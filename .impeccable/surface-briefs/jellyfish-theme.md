# Jellyfish theme — JELEE aquarium

Scope: `plugins/themes/dsh-theme-jellyfish/`; mode: Operate, code-led. Root PRODUCT/DESIGN describe Animal Island and are not this theme's visual authority.

Audience: desktop DSH users reading conversations and code. Preserve host layout, controls, saved accents/contours/fonts, desktop gate and disposal. User supplied a two-panel reference inspired by https://jelee.net/ and explicitly selected white body text with darker backing (2026-11-06).

## Direction contract

**THESIS** — A full-bleed purple-pink day / ocean-blue night aquarium, not pale stationery or a tiled star wallpaper. White type and outlines remain the identifying contrast.

**OWN-WORLD** — Lavender #a98cf0 to pink #f5a9cd; blue #3a72e0 to navy #0a1a56. After the rejected 0.5.0 desktop capture, the dark conversation must expose the blue-to-midnight ramp without a whole-column veil. Stable backing belongs to code, composer, popovers and tool panels; light mode retains its plum reading backing pending separate review. Sparse four-point stars, outlined bubbles, diagonal streaks, fish silhouettes and two bottom wave contours. Four character colours remain selectable. Outlined serif brand lettering replaces the rounded display word only; user UI/code fonts remain authoritative.

**STORY** — Users recognise the underwater mood, then continue their existing conversation, code reading and settings workflow without new navigation or decorative copy.

**FIRST VIEWPORT** — Existing left navigation, central conversation/composer and optional right panel retain their dimensions. The gradient covers the frame; the dark conversation and header stay transparent, with only a 16% blue sidebar tint. Native-size sparse motifs sit at viewport-relative edge positions. The composer has a quiet white outline without a detached squiggle; full-width 150px night waves remain visible at the lower edge.

**FORM** — User-pinned reference; no random direction substituted. No seed roll: pinned design. Only vector geometry and existing licensed brand/font resources ship; no official website artwork is copied.

**FINISH** — unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
